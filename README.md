# 輝夜大好｜個人網站

以繁體中文呈現技術實作、共學經驗、資訊應用教學規劃與登山興趣的靜態個人網站。

## 本機預覽

不需要安裝套件或建置。可直接開啟 `index.html`，或在專案資料夾執行：

```sh
npx --yes serve .
```

## 檔案

- `index.html`：自我介紹、技能、經驗、教學規劃、登山與社群連結。
- `styles.css`：響應式版面、手機導覽與減少動態效果設定。
- `script.js`：作品集渲染與篩選、Canvas 山形動畫、捲動進場、閱讀進度、手機選單與章節提示。
- `projects.js`：依公開 GitHub README 整理的精選作品資料，包含分類、介紹、原始碼與示範連結。
- `assets/hiking.jpg`：使用者提供的登山照片。
- `FB_IMG_1689556891094.jpg`、`bg.jpg`、`tailwind.config.js`：保留的原網站資源，目前首頁未使用。

## 作品集與互動

精選生活開發實驗室、NFC 數位名片教學套件、語音成績登記工具、Discord Bot 與這個網站。介紹依公開專案 README 整理，查核日期為 2026-11-02；教材規劃、現有功能與未來計畫分別說明。

作品集由 `projects.js` 的資料在本機渲染，不需 GitHub API 金鑰，也不會在瀏覽時向 GitHub 請求作品資料。修改該檔即可調整精選作品；若增減作品，請同步更新 `index.html` 的靜態備援連結。分類按鈕支援鍵盤操作，作品筆記使用原生 `details` 展開。

首頁使用 Canvas 繪製緩慢移動的山形線條，可手動暫停。離開首頁或隱藏分頁時，會停止繪製動畫。啟用系統「減少動態效果」時，山形保持靜態、停用捲動進場；沒有 JavaScript 時仍可閱讀主要內容與作品連結。

## 背景音樂

右下角音符按鈕可播放或暫停使用者指定的 Orangestar〈Surges〉（YouTube 影片 `QvWsAIc5mO8`）。首次點擊才載入 YouTube IFrame API 與可見播放器，不自動播放；播放期間保留 YouTube 影像與控制列。關閉播放器或按 Escape 會暫停音樂。歌曲以原影片嵌入，不下載或另存音訊。

若瀏覽器限制播放，請點播放器的播放鍵；影片限制嵌入或無法載入時，可使用面板中的 YouTube 連結。本機測試請使用 HTTP 伺服器，直接以 `file://` 開啟可能因缺少網站來源而無法播放。

2026-11-02 本機實測：這支指定影片回傳 YouTube 錯誤 150（不允許嵌入播放），因此目前面板提供原影片連結，無法在站內播放這首歌。若要直接背景播放，需改用允許嵌入的影片，或提供可供網站使用的音訊檔案。

## 個人心得

整理這個網站，也讓我重新思考自己想分享什麼。除了使用過的技術與參與過的專案，我也希望讓人看見自己喜歡學習、樂於交流，以及喜歡爬山的一面。個人網站對我來說，是整理經驗、記錄生活，也持續認識自己的地方。

在規劃資訊應用教學時，我最期待的是陪伴同學把想法一步步做成作品。從個人網站開始，再延伸到雲端服務與 NFC 應用，每個階段都可以有看得見的成果。我希望把自己的實作與共學經驗帶進教學，和同學一起討論、解決問題，也一起體會完成作品的成就感。

寫程式與爬山，是我喜歡的兩種探索方式。一個讓我動手實現想法，一個讓我走出去看看不同的風景。未來也想繼續在這裡記錄新的作品、學習心得與山野日常。
