# 輝夜大好｜個人網站

以繁體中文呈現技術實作、共學經驗、資訊應用教學規劃與登山興趣的靜態個人網站。

## 本機預覽

不需要安裝套件或建置。可直接開啟 `index.html`，或在專案資料夾執行：

```sh
npx --yes serve .
```

## 檔案

- `index.html`：自我介紹、技能、經驗、教學規劃、登山與社群連結。
- `styles.css`：響應式版面、手機導覽與減少動態效果設定。
- `script.js`：手機選單、目前章節提示與頁尾年份。
- `assets/hiking.jpg`：使用者提供的登山照片。
- `FB_IMG_1689556891094.jpg`、`bg.jpg`、`tailwind.config.js`：保留的原網站資源，目前首頁未使用。

## 內容維護

網站內容依「助教申請教學規劃」對話與使用者提供的登山興趣整理。NFC 與五階段課程均標示為規劃方向；沒有虛構開課紀錄、成果數量或私人專案連結。上線前可再核對技能與專案描述，並加入可公開展示的作品網址。

修改 `index.html` 即可更新文字、社群網址與課程路線。替換照片時，同步修改圖片替代文字與尺寸。整體樣式不依賴第三方 CDN、字型或圖示服務。

## 發布

此專案可由 GitHub Pages 等靜態主機直接提供，不需建置指令。GitHub Pages 可選擇發布分支的根目錄 `/`。
